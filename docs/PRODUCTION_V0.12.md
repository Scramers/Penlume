# Penlume 0.12.0：界面、布局与编辑效率

2026-10-04。本批根据“界面不够简洁、尺寸调整不清晰、优先提升编辑效率”的反馈更新。品牌与原有数据目录沿用 0.11.1，Windows 产物位于 `release-v0.12.0/`。

## 日常使用

- 默认只保留 44px 顶栏和底部状态栏，移除常驻左侧工具条、编辑区卡片边框、阴影及外围留白。单篇隐藏标签，多篇显示标签。正文使用更克制的默认明暗配色。
- 文件、格式、图片、导出、主题与写作工具从原生菜单或 Ctrl+K 命令搜索进入。格式工具栏可从“视图 → 切换格式工具栏”或尺寸面板显式开启。
- 点击顶栏齿轮、右下角字号/缩放读数，或“视图 → 布局与尺寸”打开设置。字号只改正文；正文宽度是最大值，随可用空间收缩；界面缩放改变 Electron 页面中的工具控件和正文显示，不改变原生 Windows 菜单或导出尺寸。
- 正文宽度提供 600、860、1120px 预设。字号范围 12–32px，界面缩放范围 75–150%。Ctrl+Alt+加号/减号调整字号，Ctrl+Alt+0 恢复；Ctrl+加号/减号调整界面缩放，Ctrl+0 恢复。
- 数字设置允许逐位输入和暂时清空，在失焦或 Enter 时提交并限制范围；空输入恢复当前值。缩进宽度、自动保存秒数保持整数。设置面板内容独立滚动，640×420 窗口及 150% 缩放下底部完成/恢复按钮仍可操作。
- 拖动侧栏边缘或源码/预览分隔线调整尺寸，双击或 Enter 恢复。分隔线可聚焦并使用方向键；Shift 加大步进。布局记忆存储在本地，恢复布局不改文档。
- 工作区可用宽度小于 900px 时侧栏覆盖正文，点击外部关闭。编辑区可用宽度小于 720px 时源码/预览上下排列，恢复宽窗口后沿用原比例。侧栏 190–420px，预览比例 25–75%。Windows 最小窗口为 640×420；本批不新增操作系统窗口位置记忆。
- 预览采用独立、较小的页内留白，上下排列的小面板也能从首段开始阅读；静态 HTML/PDF 导出的页内留白保持原有设置。

## 新增选区复制

“编辑”菜单和命令搜索增加复制选区为 Markdown、HTML、纯文本三个操作。Ctrl+Shift+C 复制选区 Markdown，Ctrl+Alt+C 复制选区纯文本。原有整篇复制保留。

正文读取真实 ProseMirror Slice，源码读取 CodeMirror 选区，代码/公式等原生输入读取所选的字面字符。HTML 只包含所选片段，使用现有资源授权与文档资源根上下文准备本地图片。无选区时明确提示，不回退到整篇文档。复制不添加文档编辑事务或撤销历史。

命令搜索接管焦点前捕获选区。异步 HTML 准备期间如正文、文档、路径、编辑器挂载或语言变化，旧请求不能提交剪贴板。不同 ID 的同名未保存文档也分别检查所有权。原生 Ctrl+C/X/V 和表格 HTML/TSV 矩形协议不替换。

首批明确拒绝跨格、矩形选区、多处非空源码选区、未知结构、悬空脚注、部分无法保真的格式边界等复杂内容。截断嵌套列表需要空父项时，当前底层序列化会将子列表变成 HTML，本批拒绝该结构而不声称保真支持。表格矩形继续使用 Ctrl+C。更广泛的外部应用剪贴板互操作和原生 IME 未在本批建立证据。

## 验证证据

- 最终完整构建及类型检查通过，57 个文件、1,138 项单元测试通过，见 `artifacts/ui-v0.12/build-size-fixed.log` 和 `unit-size-fixed.log`。初次受限单测的两个符号链接权限失败，以及新嵌套列表序列化失败均保留；权限允许的回归与实际拒绝边界修正后通过。
- 布局专项实际检查默认简洁界面、侧栏拖动/方向键/恢复、覆盖侧栏、点击外部关闭、预览方向与比例恢复、实际 Electron 缩放、宽度预设/格式栏设置、重载保留，以及 640/760/980/1180px 无横向溢出与顶栏重叠。测试文档字节不变。
- 选区复制专项包括正文部分格式/跨块、源码准确片段、嵌入输入、空/外部焦点拒绝、表格原协议、已授权资源和正文/标签/语言/挂载变更取消，以及两个同名同内容未保存文档的隔离。真正的剪贴板读写和原始资源准备处理执行；控制异步结果交付用于取消检查，不代表自然竞态频率测量。成功记录在原始观察器恢复、程序正常退出、临时目录清理后写入。
- 桌面测试的旧入口已更新：显式开启格式工具栏后检查按钮历史，主题从命令搜索进入，顶栏齿轮现在验收为“布局与尺寸”。首次旧选择器和白名单失败没有作为通过证据，日志均保留。
- 发布前复核修正了短窗口设置面板底部裁切和数字框即时夹值打断输入。新布局验收包含实际逐位键入、行高小数、整数设置、空输入恢复、上限提交、重载保留，以及最小窗口最大缩放下布局/偏好面板按钮几何与点击。早期验收错误地把带原生边框的 640px 窗口视为 640px 内容区，随后按实际内容区和 Electron 缩放因子验证；高缩放截图改用原生页面捕获。
- 最终发布程序回归、便携版启动/退出、包内构建一致性与程序哈希，以 `artifacts/ui-v0.12/ACCEPTANCE.json` 记录的实际执行结果为准。表格剪贴板专项在设置输入修复前的程序上通过；最终程序单独复核界面与编辑相关专项，不把该表格检查列为最终程序的重新执行。早期 0.12.0 程序保留在 `release-v0.12.0-initial-layout/` 和 `release-v0.12.0-before-size-input-fix/`；0.11.1 及更早版本保留。

## 范围

本批改进界面与编辑效率，不代表整体超过 Typora。长文书签映射优化、普通 HTML/PDF/PNG 导出目标保护候选未合并；长文视觉编辑性能、更多文档兼容、系统安装/升级及跨平台发布差距继续保留。Windows 程序当前未数字签名。
