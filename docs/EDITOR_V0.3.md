# 0.3.0 编辑器历史与位置恢复

日期：2026-10-02。本版本补齐日常编辑中的统一历史和位置恢复；整个 Typora 对齐与超越目标仍在推进。

## 已实现

- 每篇文档独立的撤销/重做时间线，切换写作、源码、并排视图或标签后保留。工具栏、命令面板、原生菜单、Ctrl+Z、Ctrl+Y 和 Ctrl+Shift+Z 使用同一历史。
- 连续输入合并为一步；粘贴、格式操作和模式切换建立边界；组字替换合并；撤销后新编辑清除重做分支。单文档最多保留 200 步，并限制旧历史的总文本内存。
- 撤销可恢复打开时的原始 Markdown 字符串，避免用重新序列化的文本替代原文。已保存状态按当前内容与保存内容比较，不因撤销操作强行标记修改。
- 使用 Markdown AST 原始偏移映射选区，分别处理选区开头和结尾，避免把加粗或链接的 Markdown 标记纳入选区。支持正向/反向选择，采用 UTF-16 偏移保持中文及 Emoji 位置。
- 常见标题、段落、链接、列表、表格、YAML、代码块和 HTML 源码区的选区可在模式之间恢复。代码与 HTML 内部编辑使用文档历史，设置输入框等普通控件保留自身撤销。
- 干净文档从外部重新载入时重置历史；文件冲突仍保留本地副本；关闭标签时释放对应历史。
- 专注高亮改为 ProseMirror 装饰，避免全局选区事件直接改动编辑 DOM；销毁后忽略表格节点排队的选择事务。

## 验收

- `npm test`：48 项单元测试通过，包括历史分组、原文恢复、分支、内存边界、组字替换、选区标记边界、Unicode、嵌套代码和 CRLF。
- `npm run build`：类型检查、主进程、预加载和前端构建通过。
- `node scripts/editor-history-smoke.mjs`：真实桌面键鼠操作，跨视图选区、跨视图撤销并保存原文、多标签独立历史、连续输入、分支、外部载入、设置输入、YAML/代码/HTML 编辑与选区。
- 原有 `electron-smoke.mjs`、`parity-smoke.mjs` 和 `workspace-smoke.mjs`：检查编辑、查找、导出、文件保护、草稿、多标签、退出与恢复没有回归。

以上四组桌面测试在源码构建和 `release-v0.3.0/win-unpacked/TTypora.exe` 中全部通过。打包程序另核对应用版本为 0.3.0，并验证设置输入框能撤销实际输入、文档内容保持不变。无渲染进程错误。构建使用已安装的本地 Electron 分发文件；运行目录版本时请保留同目录依赖。

测试日志位于 `artifacts/*-v0.3-source.log`、`artifacts/*-v0.3-packaged.log`、`artifacts/build-v0.3.log` 和 `artifacts/package-v0.3.log`。实际桌面截图包括 `artifacts/editor-history.png` 与 `artifacts/workspace-*.png`。

## 当前边界

- 历史只保留在当前应用运行会话中，关闭标签或重启后不恢复旧历史；恢复草稿仍保留最终文本。
- 常见节点位置已进入验收，完整的内联原子节点、复杂跨块选择、全部表格键盘边界还需更广泛样本。
- 视图切换恢复选区并把它带入可见区域；精确滚动位置和并排双向同步滚动仍待实现。
- 常规可视化编辑仍可能规范化 Markdown 写法；本轮保证撤销回到原文，不宣称所有编辑操作都逐字保持未触碰的源文本。
- Pandoc、图片资源管理/上传器、媒体、多主题、多语言和三平台发布仍见 `TYPORA_PARITY.md`。
