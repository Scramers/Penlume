## Markdown 与文件保护

- Front Matter 提供可折叠的原文编辑，不解析后重写 YAML；原生 HTML/PDF/PNG 只有开启设置后才采用标题和作者。Pandoc 转换独立读取安全 YAML 元数据。
- `[TOC]` 生成动态目录，重复标题使用独立锚点。公式、脚注、提示块及 HTML 块有实际编辑往返夹具。
- HTML 块以源码和清理后的预览同时显示。脚本、事件属性和危险链接不会进入导出。
- 打开文档后未编辑时，保存保留原始 Markdown；快速切换模式直接读取编辑状态，避免依赖延迟变更通知。
- 移动文档会重写其 Markdown 图片/链接的相对路径，保留其他原文和编码格式。已有目标文件不会覆盖。
- 文档移除存放在工作区 `.ttypora-trash`，恢复时不覆盖同名文件，图片资源不会随文档移除。
- 图片可在用户已打开的工作区内跨目录引用。未打开工作区时，仍限制在当前文档目录内；解析真实路径以限制符号链接越界。
- 有效 YAML 字符串 `typora-root-url` 统一定位图片、媒体、预览和输出；不扩大文档目录/工作区权限，不改变 `.assets` 保存位置。逆向引用生成后回读验证，资源根不支持时图片库禁止不完整扫描中的孤立资源移动。0.10.0 确认前的块／行内缩略图也使用同一文档资源解析器；被拒绝或缺失的本地引用不直接作为浏览器图片地址，确认才写入原始引用。
- 图片描述和标题独立保存，数字描述按文字保留。显式拖动缩放保存实际像素宽度，编辑器、重新打开和 HTML 输出保持一致；旧版百分比宽度仍兼容。
- 音视频共用授权目录边界，原始 HTML 不因预览清理而改写；远程媒体需要明确加载，不自动播放。上传工具仅处理当前文档引用的授权本地图片，应用成功结果保留原件和普通下载链接。
- 自动保存默认关闭；开启后仅保存已命名文档，检测到外部冲突时暂停。

## 输出

HTML/PDF/PNG 共享 Markdown 扩展解析、HTML 清理、KaTeX 数学排版和 Mermaid 渲染。带样式 HTML 内嵌公式字体，本地图片使用数据 URL，单张最多 25 MB、整篇本地图片嵌入合计 100 MB，重复引用按每次输出计数；失败、缺失、越界或超限图片使用静态引用说明。实时预览只使用已授权的本地文件 URL。PDF 可选择 A3/A4/A5/Letter/Legal、方向、边距、页眉页脚、页码和文档大纲。PNG 输出宽度为 1100 像素，高度最多 16000 像素；更长文档使用 PDF。

HTML 音视频嵌入单项最多 8 MB、合计 24 MB（含封面和重复输出）；超限/缺失资源以静态引用及导出提示保留。PDF/PNG 使用封面和媒体引用说明，实时预览使用已授权本地文件 URL。
