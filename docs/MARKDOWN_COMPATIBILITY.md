# Penlume Markdown 兼容与保真规范

> 版本：0.2  
> 状态：需求基线  
> 基线方言：CommonMark + GitHub Flavored Markdown 的显式子集

## 1. 目的

本规范回答四个问题：

1. 哪些 Markdown 语法可以直接编辑。
2. 哪些语法只预览或只保护原文。
3. 混合式 WYSIWYG 中标记何时显示。
4. 保存后对原始 Markdown 的保真程度。

未在兼容矩阵中列出的语法，默认按“保护原文”处理，不得静默删除或猜测转换。

## 2. 支持状态

| 状态 | 含义 |
|---|---|
| 编辑 | 可以在混合式编辑器中创建、修改并序列化 |
| 预览 | 可以渲染，但修改需要进入源码模式 |
| 保护 | 以保护节点或源码块显示，原文必须保留 |
| 不支持 | 不解析、不执行；尽可能按普通文本或保护节点保留 |

## 3. 语法兼容矩阵

### 3.1 MVP

| 语法 | 状态 | 里程碑 | 行为 |
|---|---|---|---|
| 普通段落 | 编辑 | MVP | 支持软换行和空段落 |
| ATX 标题 `#`～`######` | 编辑 | MVP | 活动标题显示级别入口，保存为 ATX |
| Setext 标题 | 保护 | MVP | 原文保留，Beta 后可编辑 |
| 粗体、斜体 | 编辑 | MVP | 支持快捷键和 Markdown 输入规则 |
| 删除线 | 编辑 | MVP | 按 GFM 处理 |
| 行内代码 | 编辑 | MVP | 内容不解释其他行内标记 |
| 围栏代码块 | 编辑 | MVP | 保留语言标识，围栏长度按内容安全生成 |
| 缩进代码块 | 保护 | MVP | 不转换为围栏，Beta 后评估 |
| 无序列表 | 编辑 | MVP | 新建默认使用 `-` |
| 有序列表 | 编辑 | MVP | 支持连续输入；保存允许规范化序号 |
| 块引用 | 编辑 | MVP | 支持嵌套基础块 |
| 行内链接 | 编辑 | MVP | 显示文本，提供链接编辑入口 |
| 行内图片引用 | 编辑 | MVP | 可显示本地图片；MVP 不自动复制文件 |
| 引用式链接和图片 | 保护 | MVP | 定义和引用原文保留 |
| 分隔线 | 编辑 | MVP | 新建默认保存为 `---` |
| 转义字符和字符实体 | 编辑 | MVP | 解析后保存允许规范化 |
| HTML 块和行内 HTML | 保护 | MVP | 不执行脚本；原文以保护节点保留 |
| HTML 注释 | 保护 | MVP | 不显示内容效果，但必须保留原文 |

### 3.2 Beta

| 语法 | 状态 | 里程碑 | 行为 |
|---|---|---|---|
| Setext 标题 | 编辑 | Beta | 可编辑；未触碰时保留原形式 |
| 任务列表 | 编辑 | Beta | 可点击复选框，写回 `[ ]` 或 `[x]` |
| GFM 表格 | 编辑 | Beta | 支持单元格编辑和增删行列 |
| 自动链接 | 编辑 | Beta | URL 和邮箱按 GFM 识别 |
| Front Matter | 预览 | Beta | 结构化显示，源码模式编辑 |
| 数学公式 | 预览 | Beta | KaTeX 渲染，双击或源码模式编辑 |
| Mermaid | 预览 | Beta | 渲染失败时显示源码和错误 |
| 引用式链接和图片 | 编辑 | Beta | 修改引用文本时保留定义关系 |
| 原始 HTML | 预览 | Beta | 仅渲染清理后的安全子集，源码保持可访问 |

### 3.3 V1 及以后

| 语法 | 状态 | 目标 |
|---|---|---|
| 脚注 | 预览/编辑待定 | V1+ |
| Pandoc 扩展 | 保护 | V1+ |
| CriticMarkup | 保护 | V1+ |
| 自定义容器和插件语法 | 保护 | V1+ |
| PlantUML、Vega 等图表 | 不支持/插件候选 | V1+ |

## 4. 混合式 WYSIWYG 交互

### 4.1 通用规则

- 非活动块显示接近阅读效果的排版。
- 当前块获得光标时，可以显示理解和修改该块所需的标记或控件。
- 标记的显隐不得导致光标跳到其他语义位置。
- 任何可视化操作都必须可撤销。
- 保护节点允许选择、复制和删除，但删除必须是明确的用户操作。

### 4.2 块级元素

- 标题：非活动时隐藏 `#`；活动时显示标题级别入口，是否直接显示 `#` 由 Phase 0 可用性验证决定。
- 列表：活动项显示列表标记；回车创建同级项，空项回车退出列表。
- 引用：显示引用样式；活动块保留可识别的引用边界。
- 代码块：始终显示代码区域和语言；围栏本身默认隐藏。
- 分隔线：显示为不可放置行内光标的块，可整体删除。
- 保护节点：显示“源码保护”标识和原始文本，不按 HTML 执行。

### 4.3 行内元素

- 粗体、斜体和删除线：非活动时隐藏标记；光标进入元素或选中元素时允许显示边界。
- 行内代码：保持独立样式，不渲染内部 Markdown。
- 链接：显示链接文本；点击或快捷键打开编辑浮层，外部打开必须由明确动作触发。
- 图片：成功加载时显示预览和可访问的替代文本入口；失败时显示原地址。

### 4.4 源码模式

源码模式属于 Beta：

- 使用 CodeMirror 6 展示完整 Markdown。
- 从富文本切换到源码时创建模式切换快照。
- 从源码提交回富文本时，先解析和验证，再替换富文本状态。
- 解析失败时保持在源码模式并显示错误，不丢弃用户输入。
- 两种模式使用独立撤销历史；不承诺跨模式逐字符撤销。
- 位置恢复按“块标识 → 最近标题 → 文本偏移”的顺序降级。

## 5. 保真合同

### 5.1 等级定义

| 等级 | 承诺 | 里程碑 |
|---|---|---|
| F0：无修改保真 | 文档未发生编辑时，保存命令不写盘，字节和修改时间不变 | MVP |
| F1：语义保真 | 已编辑的受支持语法重新打开后得到等价文档结构 | MVP |
| F2：保护语法保真 | 不支持或保护语法在相邻编辑后仍保留原文 | MVP |
| F3：文件属性保真 | 保留 LF/CRLF、UTF-8 BOM 和最终换行属性 | Beta |
| F4：未触碰区域保真 | 只重写被修改的块，其他块保持字节不变 | V1 |

### 5.2 MVP 保存策略

- 打开后没有编辑：跳过磁盘写入。
- 发生编辑：对支持语法进行序列化，允许整个受支持文档规范化。
- 保护节点：使用原始源码切片重新插入，不进入普通富文本序列化。
- 文件编码：MVP 只对 UTF-8 文件提供可写保证。
- 检测到无法可靠解码的文件：不得直接进入可覆盖保存状态。

### 5.3 MVP 规范化规则

- 标题新建或重写为 ATX 形式。
- 无序列表新建使用 `-`。
- 有序列表允许重新编号。
- 围栏代码块默认使用反引号；若内容包含同长度围栏，自动增加围栏长度。
- 块之间使用一个空行，代码块和列表按解析器需要保留必要空行。
- 链接和图片新建为行内形式。
- 已有保护节点不参与以上规范化。

产品文档必须明确说明：MVP 对“编辑过的文档”提供语义保真，不承诺完全保留个人 Markdown 排版风格。

## 6. Round-trip 测试

### 6.1 基本过程

每个夹具至少执行：

1. 读取 Markdown 原文。
2. 解析为编辑器状态。
3. 不编辑并触发保存，验证 F0。
4. 执行指定编辑事务。
5. 序列化为 Markdown。
6. 再次解析并比较语义树，验证 F1。
7. 检查保护源码切片，验证 F2。

### 6.2 测试集规模

| 阶段 | 最少数量 | 重点 |
|---|---:|---|
| M0 | 30 | 基础语法、中文、列表、代码块、保护 HTML |
| MVP | 80 | 组合语法、剪贴板、撤销、边界空行、错误输入 |
| Beta | 140 | 表格、任务列表、Front Matter、公式、Mermaid、源码模式 |
| V1 | 200 | 未触碰区域、跨平台换行、真实世界文档 |

### 6.3 必测边界

- 空文档、只有空行、无最终换行。
- 中英文混排、emoji、组合字符和代理对。
- 三层嵌套列表和列表中的代码块。
- 包含反引号的行内代码和代码围栏。
- URL 中的括号、空格转义和中文路径。
- 图片不存在、相对路径越级、远程图片失败。
- HTML、注释、引用式链接等保护节点前后的编辑。
- LF、CRLF 和 UTF-8 BOM。

## 7. 变更规则

- 新增可编辑语法必须增加解析、编辑、序列化和 round-trip 测试。
- 从“保护”升级为“编辑”必须说明规范化行为。
- 改变保存序列化策略必须更新 ADR 和文件安全规范。
- 任何会静默删除未知语法的实现不得合并。
