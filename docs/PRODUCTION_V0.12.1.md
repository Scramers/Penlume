# Penlume 0.12.1：排版与设置可读性

2026-10-04。根据“排版要合理、设置字号更合理、不能有难以理解的部分”的反馈更新，0.12.0 发布文件继续保留。

## 排版

- 写作、实时预览和带样式 HTML/PDF/PNG 导出共用六级标题和段落规则。标题按正文大小的 2 / 1.5 / 1.25 / 1.1 / 1 / 0.95 倍递减，标题行高为 1.35；段落遵循用户设置的行高。
- 第一块正文不再额外留出段前距，包括编辑器在前面插入虚拟光标装饰的情况。正文段距与列表、嵌套列表、引用、表格中的段距分开，列表标记高度随正文字号和行高调整。
- 正文顶部保留浮动格式栏所需的空间，避免选中首标题后格式栏翻到下方遮住下一段。真实鼠标选取与跨视图撤销回归覆盖这项修正。
- 正文宽度明确为包含左右留白的区域最大宽度。导出正文改为 border-box，与编辑器采用相同的宽度计算；预览页内留白与导出留白仍按各自用途保留。
- 基础规则在主题和用户 CSS 之前应用，用户样式可以覆盖。代码、公式、媒体、目录及表格拖拽预览等内部控件排除在正文规则之外。无样式 HTML 保持无正文样式。

## 设置

- 设置标签与输入控件 14px、分组标题 15px、说明 13px、弹窗标题 18px。正文字号变化不改变设置的字号；用户选择界面缩放时，设置面板与正文一起缩放。
- 字号、宽度、行高、缩进、保存间隔及 PDF 边距显示 px、倍、空格、秒或 mm 单位和有效范围。数字输入按 Enter 或失焦提交，可暂时清空。
- 偏好按界面、正文排版、源码编辑、输入辅助、代码块、扩展格式、文件、导出和自定义 CSS 分组。说明直接解释功能，字体选择补充阅读/简洁/代码用途；Front Matter 解释为文档开头的标题、作者等信息，CSS 标为可留空的高级选项。
- 格式写法和尺寸快捷键放在可展开的说明中。正文宽度预设显示实际像素值。小窗口使用上下排列的设置项，正文说明、输入框及底部按钮独立布局。

## 验证范围

构建、单元测试、真实 Electron 排版/布局与发布程序回归、便携版启动及构建一致性以 `artifacts/ui-v0.12.1/ACCEPTANCE.json` 的最终执行结果为准。专项通过真实偏好输入验证 12/32px 与 1.2/2.5 行高、标题层级、预览最大宽度、设置字号、描述关联、中英文及 640×420 / 150% 缩放；文档原始字节不变。

导出回归的旧 Front Matter 选项文字已更新为“使用文档信息中的标题和作者”；首次旧选择器超时日志保留，随后实际 HTML/PDF/PNG 导出回归通过，不将旧入口失败记作通过。

本批未重新建立全部二十四套桌面专项、原生 IME、系统安装升级、跨平台或 Typora 对比性能证据。复杂选区复制边界、长文性能差距和普通导出目标保护候选的未合并状态沿用 0.12.0。Windows 程序未数字签名。
