## 1. “功能对齐”的定义

0.7.0 补充大文档源码普通输入的资格快速判断，保留原辅助语义；457 项冻结单测、14 套发布程序桌面分批覆盖、便携版与大文档实际验证见 [PRODUCTION_V0.7.md](PRODUCTION_V0.7.md)。工作区首次异常与复测均保留。性能结果仅覆盖记录中的具体样本，不能宣称整体超过 Typora，以下能力差距仍按实际实现保留。

0.8.0 补齐表格 HTML/TSV 矩形复制/剪切/粘贴、空白和 CRLF 持久化、单元格首笔及连续 Shift+Enter、四类快速粘贴历史。854 项冻结单测、16 套发布程序桌面顺序验收、便携版和 222 个包内编译文件一致性通过，见 [PRODUCTION_V0.8.md](PRODUCTION_V0.8.md)。合并格、丰富原子节点、外部表格软件互操作及以下差距仍保留。

0.9.0 接入 `typora-root-url` 的文档资源上下文、逆向引用与上传上下文校验，补齐异步图片绑定、说明草稿和原生撤销保护。968 项单测、18 套发布程序一次顺序桌面验收、便携版及 222 个包内编译文件一致性通过，见 [PRODUCTION_V0.9.md](PRODUCTION_V0.9.md)。该历史版本确认前的图片链接缩略预览仍按浏览器地址解析。

0.10.0 已交付异步大纲、当前位置高亮和级别筛选，以及确认前块／行内图片的统一资源解析。1,076 项单测、二十套发布程序一次顺序桌面回归、源码及发布程序独立四组图片控件、便携版和 222 个编译文件一致性通过，见 [PRODUCTION_V0.10.md](PRODUCTION_V0.10.md)。该版本的大纲折叠、平铺及标题筛选差距由 0.11.0 补齐；资源存储策略与模板根等范围继续保留。

0.11.0 已交付规范序列化缓存、大纲真实树形折叠、平铺和标题文字筛选。1,108 项单测、二十一套发布程序一次顺序桌面回归、最终源码及发布程序独立四组图片控件、便携版和 222 个编译文件一致性通过，见 [PRODUCTION_V0.11.md](PRODUCTION_V0.11.md)。活动隐藏标题只投影到可见真实祖先，搜索显示全部匹配及祖先并保留各文档独立状态。单次百万字符观察未证明整体性能或视觉超过 Typora。

功能对齐同时满足以下三项：

1. 用户可以完成 Typora 对应的主要任务，而不是只看到相似按钮。
2. 同一 Markdown 文件在两者之间往返时，受支持内容的语义和资源路径保持正确。
3. 文件安全、冲突处理和不受信内容隔离不得为了视觉一致而降级。

不属于对齐目标的内容：Typora 激活/许可证系统、官方更新服务、匿名遥测、品牌外观、专有主题文件及官网账户。操作系统独有能力按 Windows、macOS、Linux 分别实现等价体验。

## 2. 状态定义

| 状态 | 含义 |
|---|---|
| 已具备 | 当前代码中已有可运行实现并进入测试范围 |
| 部分具备 | 主路径可用，但缺少 Typora 的配置、边界行为或高级操作 |
| 待实现 | 尚无可交付实现 |

## 4. 交付批次

### P1：日常写作功能对齐

源码模式、完整核心 Markdown、表格/公式/图表、工作区、两类侧栏、查找替换、快速打开、全文搜索、图片插入、专注/打字机模式、准确字数统计和 Windows 安装包。

### P2：生产力与输出对齐

文件操作、最近项目、主题与偏好设置、拼写检查、高级剪贴板、HTML/PDF/图片导出、英文界面和可访问性。

### P3：平台与扩展对齐

Pandoc、自定义导出命令、图片上传器、三平台正式发布、ARM、命令行和平台专属集成。

## 5. 对齐验收

- 每项“已具备”必须至少有自动化测试或明确的人工测试步骤。
- 每种 Markdown 节点必须有 Typora 生成样例、本项目生成样例和双向往返样例。
- 不以破坏原始 Markdown、关闭沙箱或放宽路径授权换取功能一致。
- 每次参考版本升级先更新本矩阵，再决定是否调整发布范围。
