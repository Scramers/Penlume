# 0.2.0 工作区验收记录

日期：2026-10-02。此版本交付多文档工作区和界面改版，完整的功能超越目标仍在推进中。

后续更新：0.3.0 已补齐文档级统一撤销及常见节点的跨视图/标签选区恢复，最新验收与剩余边界见 [EDITOR_V0.3.md](EDITOR_V0.3.md)。下文保留 0.2.0 当时的验收状态。

## 已实现

| 入口 | 行为 |
| --- | --- |
| 文档标签栏 | 同时打开多个文件；独立修改、脏状态和冲突标记；关闭单个文档时提供保存/丢弃/取消；方向键切换标签 |
| Ctrl+K 或顶部搜索框 | 命令搜索，覆盖文件、视图、格式、查找、导出、写作和设置；方向键选择、Enter 执行、Esc 关闭 |
| 编辑区「并排」或 Ctrl+Shift+V | 左侧编辑 Markdown，右侧实时渲染；本地图片嵌入预览，公式和 Mermaid 使用现有渲染链；预览禁止脚本执行 |
| Ctrl+Alt+S / 文件菜单「保存全部」 | 保存所有已修改标签，后台保存结果按文档 ID 更新，不切换当前文档；错误或冲突时转到对应文档 |
| 写作目标 | 每篇文档独立的正文字符目标，持久化、进度显示、预设与清除；统计不含空白；另存为时迁移目标 |
| 偏好设置「恢复上次文档与工作区」 | 恢复所有已命名标签和最后活动文件；未命名或未保存内容仍通过恢复草稿处理 |
| 自动保存 | 开启后保存所有已命名且无冲突的脏文档，包含后台标签 |

## 文件保护

- 切换、新建和打开文档前直接读取编辑器当前值，不依赖延迟 Markdown 通知；当前编辑器的身份与活动文档分开核对，防止快速切换时读入其他文档内容。
- 重复打开同一路径激活已有工作副本，保留未保存内容。Windows 路径比较忽略大小写并统一分隔符。
- 每个打开的文件独立监视；后台外部修改自动重载干净副本，脏副本保留内容并记录冲突，切回时处理。
- 另存为拒绝其他已打开标签使用的目标路径。
- 原生关闭窗口先请求编辑器捕获最后输入，再检查全部标签的脏状态；保存全部、保留全部恢复草稿、放弃全部或取消均覆盖整个会话。
- 草稿按文档 ID 排队写入及清理，避免旧的防抖写入覆盖新内容，或保存后重新生成旧草稿。
- 恢复草稿对应的原文件已经打开时，创建未命名恢复副本，保留两个版本。

## 外观

独立设计的蓝紫色工作区、活动导航栏、文档标签、编辑工具行、三种视图切换与状态栏。明亮和暗色共享语义颜色，小窗口收起次要文字；保留键盘焦点和减少动画偏好。截图由实际 Electron 应用生成，位于 `artifacts/workspace-*.png`。

## 验证

- `npm test`：37 项单元测试通过，包括跨文档延迟保存、重复打开、关闭邻接标签、并发草稿写入和清理。
- `npm run build`：类型检查、主进程、预加载和前端构建通过。
- `node scripts/electron-smoke.mjs`：编辑、查找替换、源码、Mermaid、大纲、统计、草稿、主题和 IPC 路径限制。
- `node scripts/parity-smoke.mjs`：Markdown 原文保存/编辑往返，HTML/PDF/PNG 导出，文件改名、移除与恢复，最近项目、设置和会话恢复。
- `node scripts/workspace-smoke.mjs`：多标签最后输入保留、后台冲突、保存全部、命令面板、实时预览、本地图片、脚本清理、目标持久化、小窗口布局、重复打开、会话恢复及原生退出草稿。

以上三组桌面测试同时在源码构建与 `release-v0.2.0/win-unpacked/TTypora.exe` 目录版本中通过；目录版本另验证了后台自动保存和实际选择「保留草稿并退出」后，命名及未命名文档均保留最终内容。构建使用已安装的本地 Electron 分发文件，无需重新下载 Electron。该目录程序运行时必须保留同目录依赖文件。

## 仍需完成

本版本没有宣称超过 Typora 的全部功能。完整差距见 `TYPORA_PARITY.md`：Markdown 节点组合和编辑边界的逐项验收、跨视图统一撤销与精确位置映射、Pandoc/自定义导出、图片资源管理与上传器、媒体、主题库、多语言及跨平台发布仍待推进。当前标签切换会重新建立编辑器，文本保留，但撤销历史和选区尚未跨标签持久化；并排模式暂不提供双向同步滚动。
